# Archived project notes

This folder keeps completed implementation plans, resolved incident reports,
and deferred ideas for historical context. These documents are not an active
backlog or specification; current behavior is documented one level up in
`docs/README.md` and `docs/ARCHITECTURE.md`.

- `PLAN.md` — early project roadmap.
- `PLAN-ADAPTIVE-RESOLUTION.md` — original adaptive-resolution design.
- `PLAN-MODARCHIVE.md` — early ModArchive integration plan.
- `PLAN-PLAYER-ARCHITECTURE.md` — proposed async player refactor.
- `FAVORITES-PLAN.md`, `I18N-PLAN.md`, `PRESETS-PAGE-PLAN.md`, and
  `PLAN-WINDOWS.md` — implementation plans for shipped features.
- `NAV-MODE-SWITCH.md` — resolved navigation incident.
- `RADIO-REVIEW.md` — implementation-time radio review; current limits are in
  `../RADIO-STREAMING.md`.
- `RADIO-STREAMING-PLAN.md` — completed implementation plan; current behavior
  and remaining device checks are summarized in `../RADIO-STREAMING.md`.
- `WINDOWS-PRESET-FREEZES.md` — dated tests on one Windows 11 / Intel UHD 600
  system; this is not a general compatibility guarantee.
- `spectrum-emulator-backend.md` — deferred research; no emulator backend is
  implemented.
